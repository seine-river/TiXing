## 1. 产品定位

题醒是一款面向小学生家庭的本地优先学习记录应用。产品由三条主线组成：

1. **错题主线**：拍照 → AI 全图识别多道题和学生作答 → 选择并核对 → 归档错题 → 科学复习 → 动画讲解。
2. **问一问主线**：孩子点击大麦克风提问 → 端侧语音转文字 → AI 生成儿童友好回答 → 保留原始声音和分类归档。
3. **好奇星球主线**：基于长期问一问记录生成孩子视角的兴趣总结、家长视角的观察建议和亲子活动建议。

当前版本优先服务单一本地学生 `stu_default`，所有业务数据保存在本机应用沙箱，可通过 zip 备份迁移。应用没有云端账号、云端同步、社区服务或支付系统。

## 3. 用户与体验设计

### 3.1 角色

| 角色 | 当前实现 |
|---|---|
| 孩子 | 主要操作者：拍题、复习、问一问、看讲解、收积分 |
| 家长 | 查看报告、设置提醒、管理备份、查看好奇星球家长观察 |
| 系统 / 醒醒 | 吉祥物与 AI 人格，负责引导、讲解、回答和鼓励 |

### 3.2 体验原则

1. **大目标、少打字**：拍照、点选、语音优先，键盘仅兜底。
2. **双视角分层**：孩子界面使用“醒醒、问一问、好奇星球”等探索语言；家长界面使用“观察、建议、导出、关于”等清晰语言。
3. **阶段反馈**：AI 图片识别、语音转文字、AI 回答、讲解视频均显示阶段和进度，避免用户误以为卡死。
4. **错误可理解**：用户看到中文可执行提示；完整技术诊断进入 HiLog。
5. **保留痕迹**：错题原图和问一问原始音频是成长记录，不因 AI 状态失败而丢弃。
6. **安全兜底**：涉及危险、隐私、健康、情绪等问题时，AI 回答引导孩子找家长一起处理。

### 3.3 导航与核心入口

应用底部为四栏 + 中央特殊入口：

```text
首页 | 错题本 | `麦克风问一问` | 报告 | 我的
```

- 首页保留唯一“AI 录入错题”主入口，避免拍照功能重复。
- 中央麦克风只负责问一问，不再承担拍照入口。
- 首页展示今日复习、积分、错题统计、最近错题。
- “我的”聚合学习档案、提醒、积分、问一问、备份、家长中心和关于。

## 4. 当前功能规格

### 4.1 首页与学习概览

**状态**：已实现。

- 展示本地学生问候、日期、今日待复习数。
- 今日有待复习时显示“开始复习”；无待复习时显示“休息一下”。
- 展示积分、总错题、已掌握、复习中。
- 展示最近错题，点击进入详情。
- 主 CTA 为“AI 录入错题”。

**验收要点**：

- 数据来自数据库聚合查询，不能全量加载后内存过滤。
- 点击最近错题能打开对应详情。
- 复习入口只消费当日队列、每日上限和启用学科。

### 4.2 AI 拍题与多题录入

**状态**：已实现，替代早期 OCR / 手动圈选方案。

#### 流程

1. 用户选择“拍照识别”或“从相册选取”。
2. 系统将图片持久化到 `files/mistakes/`。
3. 本地图像质检：
   - 解码失败：阻断。
   - 模糊、倾斜、反光、暗光：软提示，允许继续。
4. 图片压缩到最长边 1800 像素并转 Base64。
5. 调用 GLM 多模态接口一次识别整张图。
6. AI 按题号拆分多道题，并识别每题：
   - 题干
   - 学生答案
   - 可见标准答案 / 批改结果
   - 知识点
   - 学科
   - 题型
   - 错误类型
   - 标签
7. 单题直接进入核对页；多题进入选择页。
8. 用户可单选、多选、全选或清空，批量保存。
9. AI 失败时进入手动填写，原图仍可保留。

**关键交互**：

- 多题选择卡片必须醒目、可明确区分选中态。
- 从多题选择页返回时回到选择列表，不能跳回首页。
- 每道题只绑定自己下方或旁边的作答，不合并长文本。

**验收要点**：

- 一张图多道题可全部录入。
- 学生答案与题干、教师批注、标准答案分离。
- AI 识别失败不阻塞手动录入。
- 保存成功才发放录入积分。

### 4.3 错题本

**状态**：已实现。

- 按学科、状态、错误类型筛选。
- 支持关键词搜索。
- 使用分页和懒加载。
- 卡片展示知识点摘要、学科、状态、录入日期和缩略图。
- 滑动删除需二次确认，删除错题与关联日志同事务。

### 4.4 错题详情

**状态**：已实现。

- 展示学科、状态、录入时间。
- 展示 AI 视频讲解入口。
- 展示知识点总结、题目、标准答案、我的答案。
- 原始照片存在时展示原图。
- 支持补充讲解笔记和图片笔记。
- 展示间隔级别、下次复习、复习历史。
- 保存修改时检查数据库结果。

### 4.5 复习与掌握判定

**状态**：已实现。

- 复习队列按 `nextReviewDate <= now`、未掌握、启用学科、每日上限筛选。
- 按题型提供作答控件：
  - 选择题：选项点选。
  - 数字题：数字输入。
  - 文本 / 主观题：文本输入或自评。
- 客观题本地归一化后自动判分。
- 主观题由学生自评一致性。
- 复习提交由 `ReviewSubmitter` 编排：
  1. 插入复习日志。
  2. 查询该错题全部日志。
  3. 掌握判定。
  4. 单次终态更新错题。
  5. 幂等发放积分。
  6. 写入埋点与性能行为。
- 复习结束显示正确率、答对数、再练数、获得积分和鼓励文案。

### 4.6 AI 讲解视频

**状态**：已实现为应用内动画讲解，不生成或下载 MP4 文件。

- 输入：题目、学生答案、标准答案、年级、学科、知识点、错误类型。
- AI 生成 4–6 个章节脚本，包含：
  - 标题
  - 总时长
  - 旁白
  - 字幕
  - 屏幕类型
  - 图形类型
  - 动画类型
- 播放器用 ArkUI 原生动画渲染：
  - 封面
  - 题目
  - 答案对比
  - 分数条
  - 数轴
  - 箭头流程
  - 图标故事
- 每章节使用 Core Speech Kit TTS 朗读。
- 支持播放 / 暂停 / 上一章 / 下一章 / 重播 / 章节列表。
- 加载阶段持续显示进度和等待秒数。

### 4.7 问一问

**状态**：已实现。

#### 录音与转写

- 用户点击醒目大麦克风开始录音。
- 最长 30 秒。
- 使用 `AudioCapturer` 直接采集 PCM：
  - 16 kHz
  - 单声道
  - 16 bit
- 写成标准 WAV 保存到 `files/voice_asks/ask_<id>.wav`。
- 使用 Core Speech Kit 端侧识别：
  - 中文 `zh-CN`
  - offline mode
  - 1280 字节音频分块
  - 40ms 间隔
  - 尾块补零
- 转写显示 `正在转换为文字… x/y秒`。
- 转写失败允许手动修正或点击麦克风重录。

#### AI 回答

- 输入：转写后的问题 + 学生年级。
- 输出结构：
  - `answerText`
  - `subject`
  - `topic`
  - `interestTags`
  - `questionType`
  - `safetyLevel`
  - `followUpQuestion`
- 页面展示回答、追问、分类和兴趣标签。
- 保存后进入我的问一问和好奇星球数据池。

## 5. AI 设计规格

### 5.1 模型与配置

当前所有生成类 AI 请求固定使用：

- Model：`glm-5.3-flash`
- Endpoint：`https://open.bigmodel.cn/api/paas/v4/chat/completions`
- Auth：`Authorization: Bearer <token>`
- API Key：仅从 `harmonyos/entry/src/main/resources/rawfile/apiconfig.json` 读取
- 动态模型 / API Key 配置 UI：不提供

`apiconfig.json` 不入库。缺失或为空时：

- 本地错题本、复习、积分、报告、备份等功能继续可用。
- AI 图片识别、问一问回答、好奇星球报告、讲解脚本提示 AI 未配置或请求失败。

### 5.2 请求参数

```json
{
  "model": "glm-5.3-flash",
  "messages": [],
  "temperature": 0.1,
  "max_tokens": 4096,
  "thinking": {
    "type": "enabled",
    "clear_thinking": false
  },
  "reasoning_effort": "low"
}
```

图片识别使用 `image_url + text` 的多模态 content 数组。

### 5.3 AI 能力边界

| 能力 | 当前用途 | 不允许 |
|---|---|---|
| 图片理解 | 拆题、识别学生答案、分类 | 不直接写库，不跳过用户核对 |
| 问一问回答 | 儿童友好解释与分类 | 不替代家长处理安全风险 |
| 好奇星球报告 | 解释本地统计 | 不生成统计数值 |
| 讲解脚本 | 生成分章动画与旁白 | 不编造题目没有的信息 |

### 5.4 可观测性与错误

- 请求日志记录模型、地址、消息数、key 长度、耗时、HTTP 状态、body 长度、usage，不记录 key。
- 长响应和错误按块输出到 HiLog。
- 用户提示使用中文可执行文案。
- 常见 401 / 1000、1113、2300028、网络失败、参数不兼容等映射为友好提示。
- 禁止向用户展示 `[object Object]`。

## 6. 核心算法规格

### 6.1 复习排期

- 正确：间隔索引 +1，上限为最后一级。
- 错误：索引归零。
- 间隔序列：`[1, 3, 7, 15, 30]` 天。
- 正确后状态为 `reviewing`。
- 错误后状态为 `unmastered`。
- 已掌握题不再进入今日复习队列。

### 6.2 掌握判定

默认条件：

1. 最近至少 2 次连续正确。
2. 最近有效记录跨至少 2 个本地日历日。
3. 每次用时不超过基准时长 60%。
4. 基准时长优先取首次复习用时，否则 60 秒。

主观自评要求额外一次连续正确，即最近 3 次。

### 6.3 连续学习

- 活动日定义为当日有录入错题或完成复习。
- 今天未学习时允许从昨天续算，当日结束后才断。
- 连击积分当天只发一次。

### 6.4 答案归一化

用于客观题自动判分：

- 去首尾空白
- 统一大小写
- 全角 / 半角转换
- 去内部空白
- 保留语义字符

### 6.5 好奇星球统计

- 领域、主题、标签均由本地记录计数。
- 排序按数量稳定排序。
- AI 报告只消费统计结果与最近最多 100 条问题文本。

## 8. 权限设计

## 10. 非功能需求

### 10.1 性能

- 错题列表使用 `LazyForEach` 和分页。
- 统计优先 SQL 聚合。
- 图片按显示尺寸降采样。
- 备份解析放入 taskpool，避免 UI 冻结。
- 复习提交只做一次终态更新。

### 10.2 可靠性

- 数据库初始化幂等。
- 写操作返回 `DbResult`。
- 删除错题与日志使用事务。
- 导入使用事务和去重。
- AI 失败不影响本地数据浏览和复习。

### 10.3 隐私

- 学习数据默认留在本机。
- 事件中学生 ID 哈希化。
- AI 请求只发送必要题目、文本或图片。
- API key 不写入日志。
- 备份由用户主动选择存储位置。

### 10.4 兼容

- 数据库从 v2 幂等升级到 v3。
- 备份兼容旧 MP3 问一问录音。
- 深浅色主题资源化。
- 页面按 HarmonyOS 手机形态设计。
