## iOS 设计移植建议

1. **保留双视角语言**：孩子侧使用“醒醒、问一问、好奇星球”等有温度的命名；家长侧使用“观察、建议、导出、关于”等冷静清晰的语言。
2. **主操作突出**：AI 录入、开始复习、中心麦克风应延续高对比、大触摸区域和明确动词；iOS 可结合浮动按钮、底部主按钮或 `TabView` 中央操作实现。
3. **流程使用阶段性反馈**：AI 图片识别、语音转文字、AI 回答、讲解视频均已有阶段文案；iOS 设计应避免单一 Spinner，保留进度和可返回说明。
4. **儿童内容与家长内容分区**：好奇星球、问一问偏插画和探索感；学习报告、家长中心、数据管理偏信息密度和可读性。
5. **系统控件映射**：HarmonyOS 页面标题可映射为 iOS 导航栏 / 大标题；底部四栏 + 中央麦克风可评估 iOS `TabBar` + 中央凸起操作；设置类页面可拆分为 iOS `Form` / `List` 分组。
